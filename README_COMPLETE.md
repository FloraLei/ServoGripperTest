# 电动夹爪控制系统 - 完整文档

## 📋 项目概览

这是一个完整的电动夹爪控制系统，支持 Arduino Uno 和 ESP32 两个平台。系统集成了：

- 🎯 Wheeltech HW020 270° 舵机控制
- 📊 INA219 电流传感器监测
- 🔘 三档位机械开关
- 📳 振动反馈马达
- 💾 EEPROM 参数存储
- 📝 完整操作日志

## 🚀 快速开始（Arduino）

### 1️⃣ 硬件连接

参考 `Documentation/HARDWARE_ARCHITECTURE.md`，连接：
- PIN 8 → 舵机信号
- PIN 2/3/4 → 三档位开关
- PIN 6 → 振动马达
- A4/A5 → INA219

### 2️⃣ 代码上传

```
1. 打开 Arduino/gripper_main.ino
2. 选择 Board: Arduino Uno
3. 选择 Port: COM X（根据实际）
4. 点击上传
```

### 3️⃣ 验证工作

打开串口监视器（9600 波特率）：


## ⚙️ 配置参数

系统有 5 个可配置参数，通过串口命令调整：

### 1. 打开角度
```
set open <0-270>     # 默认 0°
```
- **含义：** 执行 `open` 命令时的目标角度
- **推荐：** 0-20°（取决于物体大小）
- **示例：** `set open 0`

### 2. 关闭角度
```
set close <0-270>    # 默认 270°
```
- **含义：** 执行 `close` 命令时的目标角度
- **推荐：** 220-270°（取决于夹持力需求）
- **示例：** `set close 270`

### 3. 运动速度
```
set speed <1-10>     # 默认 5
```
- **含义：** 每 100ms 转过的角度（°/100ms）
- **范围：** 1=最慢，10=最快
- **推荐：** 5（平衡速度和精度）
- **示例：** `set speed 5`

### 4. 电流阈值
```
set threshold <50-1000>  # 默认 300 mA
```
- **含义：** 触发振动的电流变化量
- **推荐：** 150-300 mA（根据应用）
- **示例：** `set threshold 300`

### 5. 振动时长
```
set vibrate <50-1000>    # 默认 200 ms
```
- **含义：** 触发时振动的持续时间
- **推荐：** 100-300 ms
- **示例：** `set vibrate 200`

**完整参数说明：** 见 `Documentation/参数配置指南.md`

## 🔧 故障排除

### 问题 1：舵机不动

**检查步骤：**
```
1. 验证 PIN 8 连接到舵机信号线（白）
2. 检查舵机电源是否 5V 稳定
3. 上传 Arduino/simple_pulse_test.ino 测试
4. 如果测试也不动，舵机可能损坏
```

### 问题 2：INA219 找不到

**检查步骤：**
```
1. 验证 A4/A5 连接正确
2. 检查 INA219 有 5V 和 GND
3. 检查 I2C 上拉电阻（4.7kΩ）
4. 运行 I2C 扫描程序（见调试指南）
```

### 问题 3：按键无反应

**检查步骤：**
```
1. 验证 PIN 2/3/4 连接到按键
2. 用万用表测试按键导通性
3. 检查是否按下并释放（去抖动）
4. 检查按键没有损坏
```

**完整故障排除：** 见 `Documentation/调试指南.md`

### 迁移时间表

```

  - 调试问题

第 3 周：
  - 性能测试
  - 优化配置
  - 文档更新
```

### 关键改动

| 项目 | Arduino | ESP32 | 说明 |
|------|---------|-------|------|
| PIN 定义 | PIN 8 | GPIO 5 | 全部改动 |
| I2C | A4/A5 | GPIO 21/22 | 固定引脚 |
| EEPROM | EEPROM.put | EEPROM.put + commit | 需要提交 |
| 波特率 | 9600 | 115200 | 更快 |
| 按键上拉 | INPUT_PULLUP | 外部 4.7kΩ | 无内部上拉 |

**详细迁移指南：** 见 `Documentation/ESP32_MIGRATION_GUIDE.md`

## 📞 获取帮助

### 问题排查流程

```
1. 阅读相关文档
   ├─ 硬件问题 → HARDWARE_ARCHITECTURE.md
   ├─ 代码问题 → 注释和错误信息
   ├─ 故障排除 → 调试指南.md
   └─ 参数问题 → 参数配置指南.md

2. 检查串口输出
   ├─ 启动消息：确认硬件初始化
   ├─ 错误信息：查看具体错误内容
   └─ 日志信息：分析操作记录

3. 运行诊断脚本
   ├─ simple_pulse_test.ino （舵机测试）
   ├─ fine_search.ino （精细校准）
   └─ I2C 扫描程序（传感器检查）

4. 验证硬件
   ├─ 用万用表检查连接
   ├─ 检查电压和电流
   └─ 确认没有短路或断路
```

### 常见错误信息

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| `INA219 not found` | I2C 通讯失败 | 检查 A4/A5 连接，验证上拉电阻 |
| 舵机不动 | PIN 8 信号问题 | 运行 simple_pulse_test.ino |
| 按键无反应 | PIN 2/3/4 问题 | 检查按键连接和去抖延迟 |
| 配置重启后丢失 | EEPROM 问题 | 检查 EEPROM.commit() (ESP32) |
